Global feature explanations

SHAP describes which input features influenced this model on the demonstration dataset. These are model explanations, not proof of atmospheric causation.

☁️

Cloud Top Temp (CTT)

Convective intensity marker

CTT is included as a cloud-top thermal feature. The SHAP plots show how the fitted model used it in this dataset; they do not establish a physical threshold or causal relationship.

BT

BT Difference (TIR1 − TIR2)

Derived channel difference

BT difference is derived as TIR-1 minus TIR-2. Its contribution is learned from the training examples and should be checked against calibrated satellite data before meteorological interpretation.

OLR

OLR (Radiation)

Radiative flux diagnostic

OLR is another input to the classifier. Its SHAP value indicates model influence for the examples shown, not an independently validated rainfall signal.
