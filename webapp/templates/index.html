THE RESEARCH QUESTION

Can recent satellite measurements help identify intense rain before it occurs?

A useful answer needs time-matched satellite and rainfall observations, a stated forecast window, and an evaluation that keeps storms in the test set separate from storms used for training.

CURRENT MODEL SCOPE

This build is a demonstration, not a validated nowcast.

The bundled model was trained and tested on generated sample records. Its displayed metrics show that the software pipeline runs; they do not measure skill on real rainfall.
