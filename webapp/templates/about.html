METHOD & DATA

A small, testable nowcasting study

To answer the project question, each satellite observation must be paired with rain that occurs later. The current app does not yet contain those real paired records.

PROPOSED EXPERIMENT

One observation, one future window, one label

Keep the target and timestamps identical across every model.

  1. 01
    Read recent satellite frames

    Use calibrated, geolocated INSAT-3D/3DR imager measurements at the current time and previous available scans. Start with TIR-1, TIR-2 and water-vapour channels. Derive a short-term cloud-top cooling feature from the past frames.

  2. 02
    Measure rain after the observation

    For an observation at time t, aggregate rainfall over the next three hours. A proposed event label is an average rate of at least 20 mm/hour, equivalent to 60 mm in three hours. This corresponds to the lower edge of IMD’s “Intense Spell” category; confirm the final threshold with the project guide before training.

  3. 03
    Train and compare simple models

    Begin with logistic regression as a baseline, then compare Random Forest and XGBoost. Keep all frames from the same storm in one split to prevent the model seeing nearly identical weather in both training and test data.

  4. 04
    Explain results and inspect misses

    Use SHAP on the selected model to show which features raised or lowered the estimated risk. Report event recall, false alarms, missed events and F1 on held-out storms. Treat SHAP as an explanation of model behavior, not atmospheric cause.

DATA SOURCES

Where the real data can come from

No satellite or rainfall archive has been downloaded into this project yet.

A · INPUT

INSAT-3D/3DR through MOSDAC

Request calibrated, geolocated Imager Level-1B files and keep their timestamps. MOSDAC documents the product levels and lists a download API. Searching the catalogue is available without logging in; downloading requires an approved MOSDAC account. Start with a small regional window and a short date range.

INSAT product description·Data catalogue and download instructions
B · LABEL

GPM IMERG rainfall estimates

NASA lists half-hourly precipitation estimates at 0.1° resolution and three-hour accumulation products. An Earthdata account is required for many download routes. IMERG combines multiple satellite estimates and gauge analysis, so call it a rainfall estimate, not independent ground truth.

NASA GPM data directory·IMERG half-hour product
C · CHECK

IMD rainfall observations

Use rain-gauge observations for an independent check where the team can obtain time-matched station data. IMD’s three-hour rainfall service shows short-spell intensity categories; its 0.25° gridded archive is daily data and should not be presented as a three-hour nowcast label.

CURRENT BUILD

What is implemented

The Flask demo compares Random Forest, MLP and XGBoost on 5,000 generated feature rows, displays test metrics, generates SHAP summaries, and counts false alarms and misses. Its binary class is sampled from a simulated probability rule based on several features. Rainfall amounts are then generated conditional on that class. The generator does not create the class by applying the configured 64.5 mm/day threshold to those amounts. All sample cases and scores are synthetic; they do not test the proposed three-hour future-rain target.

Data access step: one team member should request MOSDAC access and inspect the INSAT catalogue while the team agrees with the guide on the study region, event threshold and time window. These choices are needed before the real training table can be built.
